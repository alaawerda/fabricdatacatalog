Privacy Policy - Fabric Data Catalog

Last updated: 2026-04-27

Overview

Fabric Data Catalog is a browser extension for Google Chrome and compatible Chromium browsers that helps users catalog, inspect, and govern Microsoft Fabric Lakehouse and Delta/OneLake metadata.

Data Processed

The extension may process the following data in the user's browser session:

  • Fabric workspace, lakehouse, table, schema, and metadata information.
  • Delta/OneLake table history, file metadata, table properties, and quality-check results.
  • Query inputs and results needed for extension features.
  • User configuration, local preferences, cache, and extension state.
  • Microsoft authentication state required to access Fabric resources the user is already allowed to access.
  • Optional AI enrichment input, such as selected schema and governance context, when the user configures an OpenAI API key and manually triggers an AI feature.

Data Collection

Fabric Data Catalog does not use a publisher-owned backend service to collect extension data.

The extension does not sell personal data and does not use data for advertising.

The extension uses user data only to provide or improve its single purpose: helping the user inspect, document, and govern Microsoft Fabric Lakehouse and Delta/OneLake metadata. The use of user data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

If optional AI enrichment is configured and triggered by the user, selected metadata may be sent directly from the browser to the OpenAI API. This is not enabled by a publisher-owned backend and requires a user-configured API key.

Data Storage

Data may be stored locally in the browser using:

  • chrome.storage
  • IndexedDB
  • in-memory browser state during the active session

Local cached data remains on the user's device unless the user exports it, clears browser/extension data, or the extension removes expired cache entries.

Network Requests

The extension communicates directly with Microsoft endpoints required for its features, including Microsoft Fabric, Power BI, OneLake DFS, OneLake Table API, Microsoft authentication, and related Microsoft analysis endpoints declared in manifest.json.

The extension may communicate with https://onelake.table.fabric.microsoft.com/* to read Microsoft OneLake Table API / Delta table metadata required for user-requested schema inspection, table metadata, and quality workflows. This endpoint is used as a Microsoft data API and is not used to load or execute remote code.

The extension may communicate with https://api.openai.com/* only for optional user-triggered AI enrichment when an OpenAI API key is configured.

Permissions Usage

  • activeTab and tabs: detect the active Fabric or Power BI context.
  • storage: save local settings, cache, and user preferences.
  • scripting: support page integration needed to detect workspace and table context.
  • sidePanel: display the extension user interface.
  • identity: support Microsoft authentication flows when required.
  • alarms: support scheduled quality-check workflows.
  • Microsoft host permissions: support Microsoft Fabric, Power BI, OneLake DFS, OneLake Table API, Microsoft authentication, and related Microsoft analysis endpoints.
  • OpenAI host permission: support optional user-triggered AI enrichment.

Data Retention

Local cached metadata and settings are retained until:

  • the user clears extension or browser data;
  • the extension cache expires or is removed by extension logic;
  • the extension is uninstalled.

Security

Data is processed in the browser context and sent only over HTTPS to the Microsoft endpoints required for the selected functionality. Access to Fabric data depends on the signed-in user's Microsoft permissions.

Contact

Use the support contact or support URL provided on the Chrome Web Store listing for Fabric Data Catalog.

Compliance Note

Before production publishing, host this policy at a public HTTPS URL and confirm it with the publisher's legal or compliance owner. The public policy must match the Chrome Web Store listing and the Privacy practices declarations.
