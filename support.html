Support - Fabric Data Catalog

Support information for the Fabric Data Catalog browser extension.

Contact

Use the support email or support URL configured in the Chrome Web Store listing for Fabric Data Catalog.

Recommended response target: 2 business days.

How to Report an Issue

Please include:

  1. Extension version.
  2. Google Chrome or Chromium browser version.
  3. Microsoft Fabric or Power BI page URL pattern where the issue occurs.
  4. Reproduction steps.
  5. Expected behavior and actual behavior.
  6. Screenshot or console error logs, if available.

Do not include secrets, access tokens, passwords, or sensitive business data in support reports.

Common Troubleshooting

  1. Ensure you are on https://app.fabric.microsoft.com or a supported Power BI/Fabric page.
  2. Confirm that the signed-in Microsoft account has access to the target workspace, lakehouse, and table.
  3. Refresh the Fabric tab.
  4. Re-authenticate if the Microsoft session expired.
  5. Restart the browser if the side panel does not open.
  6. For local testing only, reload the unpacked extension in chrome://extensions.
  7. For Store installs, verify that the installed version matches the latest published version.

Enterprise / Private Rollout

For controlled rollout, use:

  • Chrome Web Store visibility: Unlisted for link-only installation.
  • Chrome Web Store visibility: Private for trusted testers, groups, or domain-limited installs.
  • Enterprise deployment through Chrome Enterprise policies, Google Admin console, Intune, or GPO for managed environments.
